IB Option Allocation & Change Feasibility Tool

Four interactive diagrams of the real implementation. Each page supports dark/light themes, pan & zoom, search, relationship tracing, guided views and PNG/SVG export.

Architecture
System architecture
Browser → Next.js proxy → FastAPI routers → services → pure engines → SQLite, with the rules table and the ADMIN gate.
Workflow
New student allocation
Run (dry run) → per-block pruned search → rule check → proposal → review & edit → commit, plus the waitlist branch.
Sequence
Feasibility check then override
The read-only what-if call, the ADMIN token gate, the re-check before writing and the single-transaction apply.
Lifecycle
Change request statuses
PENDING → decision → apply → audit → APPROVED, with WAITLISTED, OVERRIDDEN and REJECTED outcomes.
